# 🌐 Web Full Stack

Repositório destinado aos **projetos, trabalhos práticos e atividades desenvolvidas na disciplina de Web Full Stack**.

A disciplina aborda o desenvolvimento de aplicações web modernas utilizando tecnologias de **Front-End e Back-End**, integração com bancos de dados, APIs, comunicação entre sistemas, segurança e escalabilidade.

---

## 📚 Sobre a disciplina

Neste curso, estudamos **Frameworks de desenvolvimento Front-End e Back-End**, com foco em:

* ⚛️ **React.js** — desenvolvimento Front-End
* 🚀 **Express.js** — desenvolvimento Back-End
* 🗄️ **Banco de Dados**
* 🔗 **REST APIs**
* 📦 **JSON**
* 🔐 **Segurança de aplicações**
* 📈 **Escalabilidade**
* 🔌 **WebSockets**
* 🧩 **Microserviços**
* 📨 **Filas de mensagens**

Ao longo da disciplina, são desenvolvidas aplicações **Web Full Stack**, integrando as diferentes tecnologias e conceitos estudados.

---

## 🎯 Objetivos

A disciplina tem como objetivo proporcionar experiência prática no desenvolvimento de aplicações Web Full Stack, aproximando os alunos de situações encontradas em um ambiente profissional de desenvolvimento de software.

Durante as atividades, são trabalhados conceitos como:

* Desenvolvimento de interfaces web;
* Criação e consumo de APIs;
* Comunicação entre Front-End e Back-End;
* Persistência e consulta de dados;
* Arquitetura de aplicações;
* Segurança;
* Escalabilidade;
* Comunicação em tempo real;
* Desenvolvimento de sistemas distribuídos.

## 📖 Metodologia de ensino

A disciplina segue um modelo de aula **híbrido**, combinando:

* 📚 Aulas expositivas;
* 💻 Aulas práticas;
* 🛠️ Desenvolvimento de projetos;
* 🔎 Pesquisas e estudos individuais;
* 👥 Trabalho colaborativo.

A metodologia utiliza o **PBL (Project-Based Learning — Aprendizagem Baseada em Projetos)**, permitindo que os conhecimentos adquiridos sejam aplicados diretamente no desenvolvimento das aplicações.

Os projetos são desenvolvidos de maneira incremental, possibilitando a evolução gradual das aplicações e proporcionando uma experiência mais próxima de um **ambiente profissional de desenvolvimento de software**.

---

## 💡 Aprendizado

Durante a disciplina, os alunos são incentivados não apenas a utilizar as tecnologias apresentadas, mas também a:

* Pesquisar novas tecnologias;
* Conhecer a evolução das ferramentas utilizadas;
* Comparar diferentes soluções;
* Identificar boas práticas;
* Escolher as melhores abordagens para cada situação;
* Desenvolver autonomia na resolução de problemas.
